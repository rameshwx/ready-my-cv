# Security model

The singleton database constraint is `id = 1`; there is no registration or account list. Passwords use Argon2id. Sessions have absolute and idle expiry, are checked on every protected request, and are revoked on logout or any credential change. State-changing requests enforce strict production Origin checks. Fastify applies CSP and standard security headers, redacts cookie/authorization headers, limits bodies and rate-limits login and public requests.

Production requires unique 32+ character `SESSION_HASH_PEPPER`, `JOB_HANDLE_PEPPER`, and a 32-byte `DATA_ENCRYPTION_KEY`, private PostgreSQL credentials, Google reCAPTCHA v2 `CAPTCHA_SITE_KEY` and server-only `CAPTCHA_SECRET`, SMTP configuration, and HTTPS. CAPTCHA verification is fail-closed for role requests and uploads. Uploads are limited to one PDF, 10 MB, 25 pages, bounded text/OCR pixels, and timed child processes. The worker uses two concurrent jobs, leases, heartbeat renewal, three processing attempts, three email attempts, exponential backoff, startup recovery, and scheduled purge. Report HTML is escaped and never contains the original CV. Rotate the default credentials immediately through `/admin`.
